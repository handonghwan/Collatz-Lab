What is the Collatz Conjecture?

Proposed by German mathematician Lothar Collatz in 1937, the Collatz Conjecture (also known as the 3n + 1 problem or hailstone sequence) examines a simple iterative function defined on positive integers:

f(n) = n / 2      if n ≡ 0 (mod 2) [Even]
f(n) = 3n + 1     if n ≡ 1 (mod 2) [Odd]

The conjecture asserts that regardless of which positive integer n you start with, repeatedly applying this rule will always eventually reach the number 1 (entering the trivial cycle 1 → 4 → 2 → 1).

Precision & Scaling Architecture

Collatz Lab performs all arithmetic using native arbitrary-precision BigInt integers, eliminating IEEE-754 floating-point rounding errors. When trajectories exceed JavaScript's Number.MAX_SAFE_INTEGER (253 − 1), chart coordinates automatically apply logarithmic/scaled projection while preserving exact BigInt strings in tooltips and sequence cards.

Mathematical Status Disclaimer:
The Collatz Conjecture remains an unsolved mathematical problem. Testing individual numbers, even extremely large ones, does not constitute a mathematical proof.
